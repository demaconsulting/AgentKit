# Outside the workspace

This text file lives beside the sample's workspace folder, not inside it. It exists so a
request such as "count the words of ../outside.txt" is a genuine containment decision: the
`docstats_wordcount` tool routes the path through `PathPolicy`, which refuses it because it lies
outside the one granted location, and the tool returns `Denied (PathNotPermitted)` rather than
reading a file it was never granted.
